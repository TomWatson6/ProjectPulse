# Asset provenance

- **Afterlight score:** an original fixed 128 BPM composition created for this project. `Assets/Pulse/Editor/AfterlightComposer.cs` synthesises its drums, bass, arpeggios, pads and transition into `Assets/Pulse/Resources/Afterlight.wav`. The WAV is 44,100 Hz stereo PCM, exactly 45 seconds. No recordings, samples or external music files were used.
- **Visuals:** original geometry, palette definitions, meshes, shader, effects and UI layout in this project. Orbital forms, parallax scenery, the player capsule and hazards are drawn by the runtime. No external artwork or Geometry Dash assets are included.
- **Font:** Unity's bundled `LegacyRuntime.ttf`, loaded through the engine API. No system font was copied into the project.
- **Engine and UI:** installed Unity 2022.3.12f1 and its bundled modules/Unity UI package. Unity's own distribution terms continue to apply to those components.
